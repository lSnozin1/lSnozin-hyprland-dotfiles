# Cheat sheet

## Navigation (zoxide)
- `z name`: jump to a directory
- `zi`: interactive directory picker

## fzf shortcuts
- `Ctrl+T`: pick a file, paste its path
- `Ctrl+R`: fuzzy-search command history
- `Alt+C`: cd into a directory

## Search and view
- `rg text`: search inside files
- `fd name`: find files by name
- `bat file`: view a file with highlighting

## Help
- `tldr cmd`: short examples for a command
- `cheat`: show this sheet
- `cheat word`: search this sheet

# PinkPink

PinkPink is a dark VS Code color theme using the current color palette from the Noctalia theme installed on this machine.

## Install locally

Copy this folder into your VS Code extensions directory, then reload the window and select **PinkPink** from the Color Theme picker.

VS Code extensions directory:

- Linux: `~/.vscode/extensions`
- macOS: `~/.vscode/extensions`
- Windows: `%USERPROFILE%\\.vscode\\extensions`

The theme palette is based on [Noctalia VS Code Theme](https://github.com/tuibird/noctalia-vscode-theme), originally forked from Hyprluna’s Matugen theme. The extension manifest and theme file are included. The theme does not require extension code or dependencies.
